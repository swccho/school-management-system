# improve-ui

Improve the UI/UX of a Vue component or page.

Focus on:

- layout
- spacing
- readability
- responsiveness

## Improvements

Review:

- component structure
- layout hierarchy
- spacing consistency
- responsive design
- accessibility

## UI Rules

Avoid cluttered layouts.

Use:

- consistent spacing
- clear hierarchy
- readable typography

Ensure mobile compatibility.

Keep components reusable.

## Output

Return:

- improved component code
- explanation of changes
This command will be available in chat with /improve-ui
