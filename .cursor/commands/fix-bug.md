# fix-bug

Investigate and fix a bug in a Laravel + Vue application.

## Steps

1. Understand the issue
2. Reproduce the bug
3. Inspect backend logs
4. Inspect API responses
5. Check validation rules
6. Inspect frontend state
7. Identify root cause

## Debug Areas

Check:

- API endpoints
- request validation
- database queries
- Vue state
- component lifecycle
- event handling

## Fix Strategy

Prefer minimal fixes.

Avoid unnecessary refactoring.

## Output

Return:

- root cause
- fix applied
- files modified
- possible side effects

This command will be available in chat with /fix-bug
