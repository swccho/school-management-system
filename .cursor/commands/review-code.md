# review-code

Review code and suggest improvements.

Focus on:

- Laravel best practices
- Vue best practices
- security
- performance
- maintainability

## Backend Review

Check:

- controller size
- validation
- database queries
- N+1 issues
- authorization

## Frontend Review

Check:

- component size
- state management
- composables usage
- template complexity

## Output

Provide:

- issues found
- suggested improvements
- refactoring recommendations

This command will be available in chat with /review-code
