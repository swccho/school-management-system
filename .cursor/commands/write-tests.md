# write-tests

Generate PHPUnit tests for Laravel code.

## Test Types

Feature Tests

Used for:

- API endpoints
- authentication
- authorization
- validation

Unit Tests

Used for:

- services
- actions
- helpers

## Coverage

Each endpoint must test:

- success case
- validation failure
- unauthorized access
- edge cases

## Tools

Use:

- model factories
- RefreshDatabase
- HTTP test helpers

This command will be available in chat with /write-tests
