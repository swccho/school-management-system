# Vue UI Refiner

Improve existing Vue UI.

## Focus Areas

- **Spacing** — Avoid dense layouts; use consistent spacing (e.g. Tailwind `p-4`, `p-6`, `gap-4`).
- **Visual hierarchy** — Use size, weight, and color to guide the eye; headings and sections clearly distinct.
- **Readability** — Improve typography (line-height, font sizes, contrast) and alignment.
- **Responsiveness** — Layouts and typography scale for mobile, tablet, and desktop; touch targets adequate on small screens.

## Goals

- Reduce clutter.
- Improve usability.
- Ensure mobile compatibility.

## Rules

- Avoid dense layouts.
- Use consistent spacing across components and pages.
- Improve typography and alignment; keep text legible and aligned.
- Ensure components remain reusable — no one-off styles that break reuse.

## Quick Checklist

- [ ] Spacing consistent (padding/margins/gaps).
- [ ] Clear visual hierarchy (headings, sections, emphasis).
- [ ] Readable typography and alignment.
- [ ] Works on small viewports; no hover-only critical actions.
- [ ] Components still reusable.
